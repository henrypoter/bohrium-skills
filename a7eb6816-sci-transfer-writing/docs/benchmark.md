# 公平对照证据：无台账直写 vs 本强度审计流程（确定性路径）

## 一、对照口径（四同）

- 同源文：tests/fixtures/source.txt（虚构夹具，非正式案例）；同读者：公众；同体裁：科普文章；同篇幅：成稿 ≤300 字量级；同评分表：check_report 9 违规类 + 2 提示类字段。
- 路径 A「无台账直写」：基础 Agent 直接成稿，无机器核验。
- 路径 B「本流程」：extract 建台账 → 成稿 → check 核验 → 处置 → result.json。
- 复跑：`python3 tests/run_tests.py`（exit 0；下表数字为该脚本实测输出）。

## 二、实测对照表（2026-11-16 复跑）

| 度量 | 路径 A（无台账直写） | 路径 B（本流程） |
|-|-|-|
| 夸大检出能力（建议/因果/外推/强度词） | 0（无检测器，依赖人眼） | 变异夹具 7/7 类必命中 |
| 正向误杀（干净稿误报） | — | 0/8 违规类字段（含源文自带强度词同级保留不报） |
| 限定语覆盖率 | 无人核对 | 3/3 组强制核对；论断整体删除不误报 |
| 被删证据可检出 | 无 | v_deleted 夹具报遗漏数字 3 项，可人工处置 |
| 机械核对模型请求 | ≥1（模型自查，且不稳定） | 0（标准库脚本） |
| 产物数 | 1（仅成稿） | 4（成稿 + 台账 + 核验报告 + result.json 含映射/清单/缺口） |
| 人工核对范围 | 全量比对：12 个数字键 + 全部论断 + 4 组限定语 | 仅处置报告非零项（正向稿为 0 项） |
| 中断保底 | 无 | 先写 partial result.json，任何时刻留可用结果 |

## 三、真实 bug 复现记录（v2 → v3）

以下缺陷均由夹具先行复现、修复后夹具归零：

1. **「使得」误报因果越级**：v2 对干净稿报 `causal_escalation=[使得]`（源文「提升了」与稿「使得…更快」为同义改述）→ v3 移出因果词表，弱承接词改由工作流第 2 步人工通读把关。
2. **图表/引用编号污染数值台账**：v2 把「图 2」的 2 计入数字，干净稿被误报遗漏 `['2']` → v3 数值抽取前剔除 FIGREF/CITE 匹配段。
3. **论断删除误报限定语丢失**：v2 对删除「初步线索」子主题的稿误报 `caveats_missing=[初步/小样本]` → v3 句级留存判定（数字键或四字片段均不残留则该组不强制）。
4. **文件缺失/参数不足崩溃**：v2 抛 FileNotFoundError traceback（exit 1）→ v3 友好错误信息 exit 2。

## 四、边界声明（不声称项）

- 本对照只覆盖**机械可核验层**（事实保真、边界、结构）。端到端成稿质量与效率增益以平台固定案例、基础 Agent/Skill Agent 对照为准，本包不声称该部分数值。
- 路径 A 的「0 检出能力」指无检测器这一结构性事实，非对基础 Agent 某次具体运行的评价。
- 夹具为虚构材料，仅证明检测器行为，不代表正式案例难度。
