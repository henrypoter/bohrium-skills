# 定位与创新证据：相对基础 Agent、通用写作工具与人工改写流程

## 一、能力矩阵（✓ 稳定具备 / △ 能做但不稳定或需人工盯 / ✗ 不具备）

| 能力 | 基础 Agent（无 Skill） | 通用写作助手（润色/语法类） | 纯人工改写流程 | 本 Skill |
|-|-|-|-|-|
| 受众画像→取舍策略→边界标注→多文体映射链条 | △ 靠即时提示，跨案例不稳定 | ✗ 无源文约束概念 | △ 依赖个人经验 | ✓ genres.md 成文规则 + 骨架 |

## 二、价值主张

1. **把「说得准」从审校者记忆变成机器核验**：事实漂移（新增数字、相关写因果、限定语丢失、外推产业化）是基础 Agent 改写的高频失败模式，本 Skill 为其提供确定性检测器（tests/run_tests.py：正向零误杀、7 类变异必命中）。
2. **把「接得住」落成数据契约**：每处删改带 source_locator + action + reason，原作者按段复核，第三方按 check_report 复算。
3. **模型请求只花在理解与成稿**：机械核对全部卸载到标准库脚本，对照「无台账直写」路径核对成本从全量比对降为只处置报告非零项（docs/benchmark.md）。

## 三、边界声明（不做什么）

- 不做无源文的自由创作；不联网补充材料外信息（涉密/未发表场景同样适用）。
- 不判断学科正确性本身，只核对改写稿与源文的一致性；源文本身错误列入 open_questions。
- 非数字类新增结论（如源文没有的机制解释）无机器拦截，靠人工通读步骤与成稿规则约束。
- 不替代平台的公平对照：端到端质量/效率增益以组织方固定案例对照为准。
- 词表（强度/因果/建议/限定语/研究对象）为保守核心集，覆盖中英高频词；领域专用词需按 data_formats.md 维护节扩表。
