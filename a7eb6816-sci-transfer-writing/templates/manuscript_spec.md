# 成稿验收规格

1. **任务完成**：是 task 指定体裁的完整可编辑稿，受众、语言、篇幅和指定小节均满足；不是写作建议。
2. **来源闭合**：`evidence` 无 fail；每条 quote 有实际文件与行/字段定位；正文无悬空 id。
3. **事实保留**：required 项全部进入正文；数字+单位逐字回本句证据；样本、比较基准、限定条件、图表和引用未当冗余删掉。
4. **边界一致**：初步/相关/观察/不显著证据没有升级；同一概念只有 canonical 一种说法。
5. **受众可读**：首次缩写展开，公众稿能看到 plain 白话解释；没有未声明缩写。
6. **逐段可接稿**：每段有 before/after/action/reason/evidence；删除有理由，干净稿与复核稿只差来源标签。
7. **诚实交付**：output_contract 全字段、partial 原因、异常与不确定性完整；gain 不伪造平台 baseline。

完整 JSON 字段见 `result_spec.md`；机器验收命令见 `../SKILL.md`。
