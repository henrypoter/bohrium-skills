# 修订说明（v2 → v3）

本轮将“给经验参数”升级为可实际运行、可重放的有限域约束搜索。只改本题目录；无第三方包、无正式案例预写答案、无杜撰基线或榜单成绩。

## 1. 实际效果（40）

- **完整闭环**：新增 `optimize/replay`，从 problem 的有限域做全笛卡尔积，逐点保存响应、成本与拒绝原因，推荐确定排序首项，再以整对象哈希重放。停止原因必须对应完整网格或完整网格后的无可行解。
- **正确性**：Decimal 实算上下限、步进、组合约束、响应模型、机时/费用/样本和预算；NaN/Infinity、min>max、不齐模型返回非零。`replay` 对比完整优化产物，不只是比较推荐值。
- **完整性**：结果新增响应测量口径、不确定度、搜索初始点/轮次/停止条件、三成本口径、假设变量对照设备风险与专家确认。缺数据走 `not_checked`，不默认满足。
- **可核验性**：`result_schema_version/tool_version/plan_version/problem_sha256` 齐备；`verify` 实读源文件验 SHA-256、JSON Pointer 和逐字引文，`input_digest/permissions_digest` 固定对照版本。

## 2. 使用增益（25）

`gain BASELINE SKILL --out` 强制同 case、输入哈希、权限哈希和同口径规则，实测交付段、带定位判断、异常覆盖、可行推荐；效率仅在有双方真实 telemetry 时记录 runtime、筛选返工与改参返工轮次。无基线时强制 `not_run+reason`，不以本地合成 bench 冒充基础 Agent 对比。

## 3. 创新增益（15）与边界

- **约束感知穷举+成本响应双硬过滤**：基础 Agent 常能写搜索建议却难稳定留下全部计算轨迹；本工具可逐点复核。
- **可行域归一化效用+Pareto**：单一“最优”不能越过成本、样本和安全边界；权重影响显露而非藏在 prose。
- **量程反推**：`params` 支持同名多来源交集、步进、单位、空交集核验。
- **整轨迹 replay**：能区分模型/约束/成本版本变化导致的推荐变化。

边界：当前只支持有限网格、显式线性模型/约束和确定性权重。高维连续空间、贝叶斯优化、非线性/随机代理、多保真数据须转专用科学计算流程；不把声明的模型输出冒充实测，也不自动放宽冲突约束。

## 4. 可靠体验（10）

异常寄存器逐条覆盖题面六情形：无可行解、约束冲突（含目标温度与耐温冲突）、数据缺失、设备报错、指标矛盾、权限不足。每条含 signal、具体 action、降级/标注/人工/停止、owner 和绑定字段；风险另有 trigger/mitigation/stop_rule。网格超 max_evaluations 直接拒绝，杜绝假收敛。

## 5. 生态贡献（10）

更新 `SKILL.md`、`docs/README.md`、`templates/plan_spec.md`；新增合成 `problem.json`、`example_input.json`、真实运行生成的 `optimization.json` 和完整 `good_result.json` 最小示例。`bench/bench_run.py` 共 **33 项**，最终 **33/33 PASS**，每个命令均有正向零误杀和变异必命中。

没有组织方三例、白板、基础 Agent 原生轨迹或榜首产物，无法证明正式环境质量/效率领先。当前剩余差距主要是异构非线性响应建模、真实历史数据不确定度拟合、连续/高维搜索、复杂设备在线错误恢复，以及多案例长文档证据语义正确率；这些只能由后续真实输入与专家评审验证。
