# 定位与边界（相对已有方案的能力矩阵）

本 Skill 的定位：把学术翻译中**可机械核验的保真子集**（术语、数字/单位、引用、块对齐、否定/模糊提示）从 prompt 口头约束下沉为确定性脚本，让基础 Agent 的译文在交付前经过可复跑的质检闭环。它不替代模型的翻译能力，也不做端到端润色。

## 相对「机翻+人工校对」的增益点

人工校对的工时大头正是术语统一、数字/引用核对、对照排版三项重复劳动；本流程将其转为脚本输出+人工只看 flags，把「逐字核对」降为「逐项确认」。见 bench/compare_report.md 的确定性对照。

## 边界（不做什么）

1. **不判断学科正确性**：脚本只核对「源文↔译文一致性」，不验证源文本身的科学结论。
2. **不做语义级等价判定**：length_suspects 与 semantic.flags 是启发式 advisory，可能误报，必须人工确认，不自动改写。
3. **作者-年对消只按年份匹配**：姓氏跨语种不可确定性验证，每次对消记入 `reconciled_author_year` 供人工抽查。
4. **不联网、不调用外部服务**：全部脚本纯标准库；翻译本身由调用方 Agent 在预算内完成。
5. **中文数字解析限常见整数/一位小数形式**（如 二十三亿、百分之二十），不支持复杂口语数词。
6. 语向仅中英双向；其他语向 status="failed"，不硬译。
