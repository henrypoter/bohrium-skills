# 公平对照报告（确定性夹具 A/B）

复跑：`python3 bench/compare.py`（纯标准库，exit 0，结果写入 `bench/compare_results.json`）。

## 设计

同一份自拟英文源稿（4 块，含术语、数字/单位/年份、编号引用 [12]/[13]、作者-年引用、否定与模糊限制语）分别配两份译文夹具，由**同一套 QC 脚本**（align/check_terms/check_integrity）打分：

- **baseline_raw_translation**：模拟无工具直译的典型错误——术语漂移到禁用译法（钙钛矿太阳电池）、26.1→26 四舍五入、丢 [12] 与 (Smith et al., 2022)、否定反转（does not yet→满足）、量级错位（0.5 thousand→0.5 美元）、整块题注漏译。错误模式取自 selftest 变异夹具。
- **skill_pipeline**：按本 Skill 工作流产出的译文（术语锁定、数字/单位/引用原样、块一一对齐）。

## 度量与结果（compare_results.json 原值）

| 度量 | 无工具直译 | 本流程 |
|---|---|---|
| 术语一致性率（check_terms ok/total） | 0.6667 | 1.0 |
| 数字单位完整率（1 − 缺失/多出 ÷ 源项数） | 0.4444 | 1.0 |
| 引用完整率（编号+作者-年，跨语种对消后） | 0.3333 | 1.0 |
| 漏译率（缺失块 ÷ 源块数） | 0.25 | 0.0 |
| 语义警示数（否定/模糊/因果） | 1 | 0 |
| 三报告 pass | false/false/false | true/true/true |

效率侧（确定性事实，非工时测量）：术语统一、数字/引用核对、对照排版三项人工动作在本流程中由脚本完成，单案例命令 ≤6 条（见 examples/minimal_example.md）；人工只需处理报告中的 flags/人工确认项。

## 边界（诚实声明）

1. 两份译文均为**自拟夹具**，不是平台固定案例、也不是基础 Agent 的真实输出；baseline 的错误密度是人为设定的，不代表任何具体模型的错误率。
2. 度量只覆盖**脚本可判的保真子集**（术语/数字/引用/块对齐/否定模糊计数），不度量语言流畅度与端到端翻译质量；后者须以平台 harness 的加载/不加载对照为准，本包不声称该结果。
3. 语义警示为启发式 advisory，需人工确认，不构成自动判错。
