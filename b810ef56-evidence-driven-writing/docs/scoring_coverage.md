## 未覆盖项（如实声明）

1. **LLM 端到端写作质量对照**（得分点 5 标「部分」）：需平台 harness 在 3 个固定案例上
   对基础 Agent / 加载 Skill 的 Agent 运行，提交物内只有确定性路径对照，不越界声称。
2. **多学科真实语料实测**（得分点 12 标「部分」）：规则本身学科无关，但现有样例为单一
   自拟虚构案例，未实测其他学科真实材料；PDF 双栏/复杂版式抽取依赖运行时工具。
3. **语义充分性的最终裁决**：脚本核验一致性与可追溯性，「原文是否真在科学上支撑」
   仍以 LLM 判定为前置、专家为终审（positioning.md 第 2 节边界）。
4. 样例材料与文献均为自编虚构（文件内已标注），仅用于路径对照与脚本验证，
   不代表真实案例难度，也不是预制答案。
