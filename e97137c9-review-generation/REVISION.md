# 修订说明：文献综述生成 v2.0.0

本轮保留原有 `cite_check/theme_check/schema`，在其上补判对硬约束，没有推倒重写，也没有修改共享核心。

## 对评分维度的实质补强

- **筛选先于写作且一致执行**：新增 `screen_check`，把每条记录的 `decision` 与预先声明的 `criterion_ids` 绑定；核对待定/纳入/排除集合、重复文献反向指针和计数，避免只在文档里写纳排标准。
- **论断具体定位**：新增 `evidence_check`，在原有 record id + location 之上强制 `quote/support/evidence_strength`，并区分 `material_fact/inference/unresolved` 和结论强度；仅摘要或间接证据不得标 established。
- **主题与空白从本批文献长出**：新增 `grounding_check`，要求主题列出来源记录、归纳依据和边界，所有纳入文献均映射或解释未映射原因；主题重叠要有说明；冲突关联多条 claim，空白必须回链 claim 且限定本次检索。
- **独立复核**：`schema` 新增 `run` 版本/输入指纹与来源清单要求；新增 `provenance_check` 对 case.json 和每份实际原始材料重算 SHA-256，排除项也有来源，不只检查哈希字符串格式。
- **可靠体验**：异常表补全缺全文、元数据不全、重复、冲突、上下文超限、检索为空，并新增接口解析失败、权限不足；每种情形规定状态降级和 `unchecked/uncertainty` 记录。
- **生态复用**：证据表模板增加 claim 类型、逐字摘录、支持关系和证据强度；最小合成 fixture 覆盖完整接口，并明确非正式答案。

## 相对基础 Agent 的新增边界

基础 Agent 可以生成流畅综述，但通常不能保证筛选决定逐条引用同一协议、主题覆盖全部纳入项、空白有 claim 锚点、输入与来源字节可复算。本 Skill 把这些易断步骤变为独立命令和机器可读错误位置，并将事实、推断、无法确定项分开。

**不越界宣称**：这些检查不证明论文真实存在、不证明引文在语义上支持论断，也不证明全局检索完整；这些仍需查看原文和检索范围。工具不包含 PDF  OCR 或在线数据库检索器，只使用运行环境已提供的工具和实际材料。平台对照未在本开发环境运行，`gain` 必须留空/null，不能由 bench 的 18/18 推断正式竞赛增益。
