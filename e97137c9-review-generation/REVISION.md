# 修订说明（对齐评分细则）

本题此前未做 v2 机制化。本轮对照 rubric 逐项补齐：

- 实际效果(40)：新增 `syn_tool.py cite_check`——每条论断必须挂引用、引用的 `record_id` 必须在文献清单内、`location` 定位到页/段，三类错误（无引用/悬空引用/缺定位）机器抓出。这正对应「每条实质论断能否被所引文献真正支持」。`theme_check` 查主题覆盖，对应「是否覆盖主要主题与方法路线」。
- 使用增益(25)：`gain` 字段要求同文献集下基础 Agent 与 Skill 对照。
- 创新增益(15)：论断-引用回路、主题从文献归纳（`theme_check` 强制每主题有带引用论断）。
- 可靠体验(10)：6 行异常表（缺全文/元数据不全/重复/结论冲突/超长/检索为空）。
- 生态贡献(10)：`templates/evidence_table.md` 可复用证据表。
