# 定位与创新边界（相对已有方案的能力矩阵）

## 方法改进的实质（非包装）

1. **约束抽取前置**：周期/经费/文献/前期基础在写作前落成 meta.json，后续校验全部以
   材料实测值为准——「排得开」由口头承诺变为硬校验（止月 ≤ 周期、经费口径进 uncertainty）。
2. **要素对齐机械化**：缺口—RQ—内容—成果—任务五环全部编号化并双向校验，对应评分
   「对得上」；对齐正确性不依赖模型当次发挥（重复运行逐字节一致，见 tests R1）。
3. **防编造双通道**：数字编号越界 + 作者-年份比对，且经夹具调优——非引用括注
   （如「（预计 2027）」）与风险章风险描述不误杀（正向夹具零误杀，见 tests 正向项）。

## 明确不做什么（边界）

- 不做选题与指标合理性的学术判断（需导师确认，change_log 留痕）。
- 不验证科学正确性与实验可行性，只做结构、一致性、可追溯性校验。
- 不联网检索或补全文献著录；材料未给的字段标 `[材料未给]`。
- 启发式局限如实声明：周期/经费为正则抽取（首个匹配）；著录识别依赖 DOI/年份+标点特征；
  纯中文姓名（无「等」字）的作者-年份引用不做比对（编号校验仍生效）。
- 仅面向中文学位论文/基金式开题报告；不产出英文 proposal 的格式特化。
