# 使用增益对照报告（确定性路径）

复跑：`python3 bench/bench_run.py`（仅标准库，实测并重写 `bench_results.json`，全过 exit 0）。
夹具：`bench_run.py` 内置自拟案例（3 篇文献 + 1 条前期基础，24 个月/30 万元）与合规草稿，
非平台正式案例。

## 对照设计

- **基础路径** = 不加载 Skill 的裸写流程：没有任何自动化校验/台账工具。表中基础路径数字是
  该工作流的确定属性（无工具则自动校验项为 0、缺陷自动检出为 0、台账需手工整理），
  **不是对基础模型能力的假设**。
- **Skill 路径** = 真实执行 `scripts/proposal_scaffold.py` 的 init/gantt/check/finalize，
  所有数字为本次实测（见 `bench_results.json`）。

## 实测结果（bench_results.json）

| 指标 | 基础路径 | Skill 路径 |
|-|-|-|
| 机械校验自动化项数（0 次模型请求） | 0 | 10（八章/引用越界/作者-年份防编造/缺口↔RQ双向/RQ闭环/[P#]绑定/甘特周期/进度↔RQ覆盖/禁用词/TODO） |
| 注入缺陷自动检出（6 类变异） | 0/6 | 6/6（文献编造、缺口-RQ脱节、进度越界、禁用词、前期基础违规、进度-RQ覆盖缺失） |
| 合规草稿误报数（正向零误杀） | —（无自动化） | 0 |
| check 复跑成本 | 需人工或模型重读全文，不可确定性复跑 | 0 次模型请求 / 约 0.1 秒 |
| 证据台账自动生成条目 | 0（手工整理） | 5（[R1..R3]+[P1]+论断映射） |
| 进度超周期硬校验 | 无 | gantt 拒绝止月>周期（exit≠0） |

## 度量边界（不声称项）

1. **LLM 端到端写作质量增益不声称**：质量对照须由平台 harness 在 3 个固定案例上运行
   基础 Agent / Skill Agent，本地无法替代，本报告不含该类结论。
2. 基础路径的「0」指**无自动化保障**，不指基础 Agent 必然写错；Skill 的价值是把核对从
   「靠模型自觉」变成「可复跑的机械校验」。
3. 夹具为自拟材料，仅用于路径对照；正式案例表现以平台实测为准。
4. 缺陷检出率 6/6 覆盖的是**已编号化的 6 类高发失真**，未覆盖语义层面的科学正确性
   （需导师/评审判断，已在 SKILL.md「适用边界」声明）。
