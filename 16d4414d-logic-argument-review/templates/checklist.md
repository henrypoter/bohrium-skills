# 逻辑与论证审查清单（五个方向）

## 1. 主张抽取
- [ ] 摘要/引言/结果/讨论的核心主张全部列出
- [ ] 每条标注 claim_type：author_claim / cited_claim / hypothesis
- [ ] 保留限定词（可能/在X条件下/相关而非因果）

## 2. 证据支撑
- [ ] 每条 author_claim 有支撑证据（本文实验/所引文献）
- [ ] 抓「结论超出数据」：证据强度 < 主张强度
- [ ] 抓「引用不支持」：引文内容 ≠ 本文用法

## 3. 推理链完整性
- [ ] 前提→结论无跳步
- [ ] 隐含假设已说明
- [ ] 替代解释已排除
- [ ] 相关 vs 因果未混用
- [ ] 无循环论证

## 4. 前后一致性
- [ ] 引言承诺 → 方法/结果交付一致
- [ ] 方法 vs 结果口径一致
- [ ] 摘要 vs 正文结论一致
- [ ] 图表 vs 正文描述一致

## 5. 严重度与建议
- [ ] 严重度有依据（是否影响主结论/可否修正/可否复现）
- [ ] fix 落到具体句子：补证据 X / 改表述 Y / 降强度 Z

## 判对三件事（每条 issue 必备）
- [ ] quote 逐字回原文（verify 核验）
- [ ] location 精确到句/段（非章节名）
- [ ] fix 可执行（非空泛）
