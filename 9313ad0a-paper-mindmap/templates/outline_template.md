# 大纲模板（复制后替换内容；标注语法：{来源: 定位} {关系: 类型} {存疑: 原因} {关联: 另一节点显示文本}）

标注只进映射表、.mm 备注（`<richcontent TYPE="NOTE">`）与 OPML 自定义属性（`_source/_relation/_uncertain/_link/_note`），不进节点显示文本。`{关联: ...}` 表示跨分支/非父子关系：写入 .mm `<arrowlink>`，SVG 上为红色虚线弧；关联目标必须与另一节点的显示文本精确一致。

## 模板 A：研究论文（背景 / 方法 / 结果 / 结论）
```
# <论文主题>
- 研究背景与问题 {来源: §1/摘要}
  - 领域需求或缺口 {来源: §1 第N段}
  - 本文研究问题 {来源: §1 末段}
- 方法 {来源: §2}
  - 材料/数据 {来源: §2.1}
  - 关键步骤或模型 {来源: §2.2}
  - 评价指标与对照 {来源: §2.3}
- 结果 {来源: §3}
  - 主要发现（含数字） {来源: §3.1 图/表号} {关系: 支持} {关联: 关键步骤或模型}
  - 次要发现 {来源: §3.2}
- 结论与局限 {来源: §4}
  - 核心结论 {来源: §4} {关系: 因果}
  - 局限与未解决问题 {来源: §4 末段} {存疑: 是否需人工确认}
```

## 模板 B：综述/多文献（主题 / 流派 / 对比 / 空白）
```
# <综述主题>
- 主题范围 {来源: 综述§1}
- 流派/路线一 {来源: 文献[1][2]}
  - 代表方法与证据 {来源: [1] 表1}
- 流派/路线二 {来源: 文献[3]}
  - 代表方法与证据 {来源: [3] 表2} {关联: 代表方法与证据}
- 横向对比 {来源: 综述§4}
  - 优势/劣势 {来源: 综述§4} {关系: 对比}
  - 共识与分歧 {来源: 综述§4.2} {关系: 冲突}
- 研究空白与展望 {来源: 综述§5}
```

## 模板 C：实验/研究方案
```
# <方案名称>
- 目标与假设 {来源: 任务说明}
- 变量与对照 {来源: 方案§2}
- 步骤（按时间） {来源: 方案§3} {关系: 时间}
- 风险与判定标准 {来源: 方案§4} {关系: 依赖} {关联: 目标与假设}
```

## 关系词集合
因果 / 对比 / 依赖 / 时间 / 引用 / 支持 / 冲突 / 概括（其他词会触发校验 warning E2；跨分支用 `{关联: ...}` 表达，不滥用关系词）。
