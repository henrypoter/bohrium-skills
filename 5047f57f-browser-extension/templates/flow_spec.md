# 流程规格（flow_spec.md）

## 1. 状态机

```
pending ──执行成功──> done
   │                    │
   └──执行失败──> failed ──按 recovery 重试──> pending
                      │
                      └──不可恢复──> blocked（需人工）
skipped：依赖被跳过或条件不满足（必须写明原因）
```

规则：
- 状态**随手记**，不要任务结束才补。
- 任何 `failed` 必须同时有 `resume_point`，否则无法续跑。
- `blocked` 与 `skipped` 不得计入"完成"。

## 2. 步骤表

| id | 步骤 | 依赖 | 输入 | 输出 | 幂等键 |
|-|-|-|-|-|-|
| W1 | 检索并下载 | — | query | files[] | W1-<日期>-<序号> |
| W2 | 字段抽取 | W1 | files[] | rows[] | W2-<日期>-<序号> |
| W3 | 写入目标系统 | W2 | rows[] | record_ids[] | W3-<日期>-<序号> |

## 3. 跨站字段映射与权限

| 源站点 | 源字段 | 目标系统 | 目标字段 | 转换规则 | 权限级别 |
|-|-|-|-|-|-|
| 文献库 | title | 笔记系统 | name | 去 HTML 标签、保留原文 | green |
| 文献库 | doi | 笔记系统 | identifier | 小写、去 `https://doi.org/` 前缀 | green |
| 内部库 | subject_id | 外部系统 | patient_ref | **禁止外传**，改为内部哈希 | red |

权限分级：`green` 可直接传；`yellow` 需脱敏后传；`red` 禁止外传（用哈希/ID 代替）。

## 4. 失败恢复表

| 失败 | 判据 | 恢复策略 | 幂等保证 |
|-|-|-|-|
| 接口 5xx | HTTP ≥ 500 | 指数退避重试 3 次 | 同一幂等键只写一次 |
| 元素缺失 | 选择器无匹配 | 回退备用选择器 → 人工 | 不回滚已完成步骤 |
| 登录失效 | 跳转登录页 | 停止，请求人工认证 | 保留中断点与已得产物 |

## 5. 交付前自检

- [ ] `trace` 无错误（依赖存在、无环、状态合法、续跑点、幂等键、权限范围）
- [ ] `resume` 给出的 `runnable_now` 与实际可执行步骤一致
- [ ] `run_log` 覆盖全部已执行步骤
- [ ] blocked/skipped 步骤在 `unchecked` 中说明原因
