## 未覆盖项（如实声明）

1. **LLM 端到端成稿质量对照**（评分点 5）：需平台 harness 跑固定案例与白板，本地只有确定性机械核对对照，故标「部分」。
2. **引文语义核验**（评分点 9）：只核验「论断挂了台账内编号」，不核验「该引文真的支撑该论断」，由人工清单兜底。
3. **跨学科真实案例实测**（评分点 12）：夹具为材料学科自拟样例；化学/生物/信息等其他学科未实测，泛化依赖通用线索词。
4. **夹具非官方案例**：`bench/fixtures/` 与 `examples/` 均为自拟材料，仅演示接口与校验能力，不代表平台固定案例难度。
