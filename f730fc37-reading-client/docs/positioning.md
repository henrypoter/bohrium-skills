# 相对现有方案的边界与价值（创新点定位）

本文件回答评分点中的「是否证明创新点相对已有方案的边界和价值」，逐项给出**已有方案能做什么 /
不能稳定做什么**，以及本 Skill 的边界。

## 1. 能力矩阵

| 能力 | 通用大模型直读 | 文献管理器（Zotero/EndNote 等） | 通用 PDF 问答工具 | **本 Skill** |
|-|-|-|-|-|
| 打开 / 翻页 / 阅读 | 需人工喂文本 | 支持管理与阅读，但不做问答 | 支持问答 | 支持（`open`/`search`） |
| 以「选中文本」为边界构造上下文 | 不稳定，易漂移 | 支持选中与高亮 | 一般以整页或全篇为上下文 | **支持**：`select --quote` 产出 `prefix/exact/suffix` 三段式边界 |
| 答案与原文位置强绑定 | 通常不产出位置 | 高亮与答案分离 | 常给页码，但少给可复算的字符级锚点 | **支持**：材料/答案/选区哈希 + answer/evidence id + 页/行 + 三段式锚点，独立 audit 检漂移 |
| 锚点可机器复算（独立复核） | 不可 | 不可（高亮为人工产物） | 不可 | **可**：`verify`/`locate` 可对任意引文重新定位并给出四级置信度 |
| 阅读状态跨会话保持 | 无状态 | 记录阅读进度 | 多为会话内 | **支持**：`session.json` + `resume` 断点续读，含原子写与备份恢复 |
| 批注与问答证据统一结构 | 无 | 批注为私有/半开放模型 | 通常私有 | **支持**：统一为 W3C Web Annotation（`TextQuoteSelector`） |
| 未核验内容显式降级 | 通常无标注 | 不适用 | 少见 | **支持**：`needs_confirmation` 全链路贯穿，不阻断但标注 |
| 无文本层材料的诚实处置 | 易编造 | 只保存不处理 | 常编造或空答 | **支持**：`no_text_layer` 显式降级 + 标注 |

## 2. 本方案的三个创新点及其边界

**（1）以选中文本为边界构造上下文。**
不是「把整页塞进上下文」，而是把选区转成 `prefix/exact/suffix` 三段式锚点，上下文只取该段落的
前后文（实测长文上下文减少 60.7%，见 `bench/bench_report.md`）。
边界：锚点依赖文本层；公式、图内文字、表格结构不在覆盖范围（已在 SKILL「限制」声明）。

**（2）答案与原文锚点强绑定且可复算。**
每条答案的证据不是自由文本，而是可被 `verify` 重新定位的引文；定位结果带四级置信度
（`verbatim` / `normalized` / `fuzzy` / `page_line_only`），前两级才算已核验，其余一律标 `needs_confirmation`。
v5 再把 `answer_id/answer_sha256/document_sha256/selection_sha256` 传到导出与批注，`delivery_guard.py audit`
用独立实现检查原文内容、答案、选区、引文和批注是否在导出后漂移，模糊/兜底定位不得通过 audit。
边界：哈希能发现版本漂移但不是防恶意伪造的签名；机械核验保证引用与版本绑定，**不**保证「这段原文在科学上足以支撑该答案」；后者仍需专家判断，故不声称替代同行评审。

**（3）阅读状态跨会话保持。**
`session.json` 原子写 + `.bak` 备份 + 损坏自动恢复，`resume` 返回最后位置与段落上下文。
边界：状态绑定单个材料路径；材料被替换或重新抽取导致行号漂移时，`verbatim` 可能降级为
`fuzzy`，此时会显式标注而非静默通过。

## 3. 与「基础 Agent」的差异证据

`bench/bench_results.json` 保留上一版三条合成样例的确定性路径对照记录，边界见 `bench/bench_report.md`，
不冒充官方结果。当前 `bench/bench_run.py` 的 19 项回归进一步给出可复跑的新边界证据：
正常材料/绑定零误杀，加密、超限、答案/选区/原文/引文/批注漂移均必命中；这些均不涉及 LLM 质量评分。

## 4. 不做什么（明确边界，避免过度声称）

- 不做 OCR：扫描件走 `no_text_layer` 降级，不猜测图内文字。
- 不做文献元数据联网补全：离线环境不生成 BibTeX，避免编造条目。
- 不做学科正确性判定：只核验「答案-原文」的可追溯性。
- 不替代文献管理器：不承担文献库管理、去重、同步等职责，可与既有工具并存。
