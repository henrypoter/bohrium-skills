# 相对现有长文档写作方案的边界与价值（创新点定位）

本文件回答评分点「是否证明创新点相对已有方案（基础 Agent、通用写作工具、人工模板）的边界和价值」。

## 1. 能力矩阵

| 能力 | 基础 Agent 直写 | 通用写作工具（Word/WPS/AI 写作助手） | 排版工具链（LaTeX+pandoc+人工模板） | **本 Skill** |
|-|-|-|-|-|
| 章节↔提纲↔字数预算对应 | 不稳定，易堆段落 | 有样式无论证任务分配 | 有结构模板，无字数/材料映射 | **支持**：`--plan` 确定性分配（标题/任务/字数/材料映射/缺口），零模型请求 |
| 长上下文下前文可见性 | 随篇幅恶化，后章脱节 | 无状态 | 无状态 | **支持**：逐章注入「大纲+材料片段+前文结论摘要」，上下文随章数线性增长而非随全文（实测 5 章 -87.4%） |
| 跨章节一致性机器检查 | 无，靠人工通读 | 部分有拼写/语法，无跨章术语/编号/引用/结论核对 | 编译期查交叉引用，不查术语/结论数字 | **支持**：5 条核心规则（引用无条目、图表无题注/重号断号、缩写未定义/多全称、结论数字未见结果章），带文件+行号证据；规则少而准，误杀低 |
| 检查不阻断交付 | —（无检查） | 提示可忽略 | 编译失败即无产物（fail-closed） | **支持**：advisory（issue/warn，退出码恒 0），issue 自动并入 result.json uncertainty，始终产出 manuscript.md；**不要求重写已完成章节** |
| 材料缺口的诚实处置 | 易编造 | 不适用 | 不适用 | **支持**：骨架+`【缺口】`+gaps 记缺口不编造；材料不足状态=undeterminable |
| 改动可追溯 | 对话历史难复核 | 修订模式限单文档 | git 可用但需人工纪律 | **支持**：changes.jsonl（时间/文件/规则/前后文/原因）+ result.json source_map（论断→文件:行） |
| 中断安全交付 | 预算耗尽常无产物 | 不适用 | 不适用 | **支持**：P0 先落诚实 result.json 骨架，宁 partial 不缺文件 |
| 渲染预览 | 无 | 所见即所得 | 需配置引擎与字体 | **支持**：Markdown 直出为基线，pandoc HTML/docx/PDF 增强，失败仅记 uncertainty |

## 2. 三个创新点及其边界

**（1）确定性规划层（规划不进模型）。**
提纲解析、字数分配、材料扫描与映射、缺口标注、全章骨架全部由 `thesis.py --plan`
确定性完成：零模型请求、同输入两次运行逐字节一致（实测）。
边界：提纲解析覆盖常见中文/编号格式（单行、多行、空行分隔、第N章），极端自由格式回退默认九章体系；材料映射是关键词匹配的启发式，不保证语义最优。

**（2）advisory 一致性引擎（检查不阻断，且检查项刻意少）。**
与 v2 的 fail-closed（悬空编号退出码 1 拒绝组装，平台分 50.0）相比，v3 起改为 advisory，
v5 进一步把规则砍到 5 条核心项：结果只记 issue/warn、退出码恒 0，`--finalize` 自动并入
result.json `uncertainty`——既不丢检查记录，又不因检查拖瘦成稿（v3/v4 平台分 67.0）。
成稿优先的顺序（写满→组装→最后检查）是本 Skill 与「先立规则再写」路线的根本差异。
边界：只覆盖机器可判规则；「引用观点被改写」「无数字的说法矛盾」等语义冲突超出规则范围，
转 `[待人工确认]` + review_items。

**（3）中断安全的增量交付。**
P0 先落诚实 result.json 骨架（含 output_contract 全字段），之后每步增量改进；
预算告急立即 finalize，宁 partial 不缺文件。`--init` 重跑不覆盖已有结果（EXISTS 保护）。
边界：恢复的是「交付契约」层面，章节正文续写依赖 chapters/ 分章落盘的既有文本，
不做跨进程锁。

## 3. 与「基础 Agent」的差异证据

`bench/bench_run.py`（一键复跑，exit=0）在自拟双案例上对照：上下文 13225→1660 字符，
手工易错动作 6 类→0，一致性留痕 0→5 条核心规则（正向零误杀），结构化产物 1→11 件。属确定性路径对照，
不声称 LLM 端到端写作质量更优（边界见 `bench/bench_report.md`）。

## 4. 不做什么（明确边界，避免过度声称）

- 不做语义查重/抄袭检测，不做学科正确性判断（数字只查「结论章 vs 结果章一致」，不查「对不对」）。
- 不做「越写越严」的机制堆叠：不为检查覆盖率增加规则或阻断点，篇幅下限只提示不阻断。
- 不联网补文献元数据、不生成 BibTeX（离线环境，避免编造条目）。
- 不做多轮修改的三方自动合并（只有留痕可回退）。
- 不替代排版系统：渲染为预览增强，正式排版仍交 LaTeX/Word 工作流。
