# 支持度判定锚点（support_rubric.md）

| 支持度 | 判定 | 需要证据 |
|-|-|-|
| full | 原文明确陈述该结论 | 1+ 条逐字引文，定位到页/段 |
| partial | 原文支持一部分，其余为推断 | 1+ 条引文 + 注明哪部分是推断 |
| none | 原文与此矛盾 | 引矛盾处原文 |
| unknown | 材料未报告 | 写明"材料未报告 X"，不给引文 |

## 误报抑制
1. 引文必须逐字，跑 `support_check --text` 核验；不在原文的条目删除或改写。
2. 同一事实不重复引。
3. 拿不准一律 `unknown`，不凑支持度。
