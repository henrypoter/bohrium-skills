# 研究方法与统计审查清单（v3）

> 每项都记录 checked / not_applicable / pending / unchecked；“未发现问题”也是检查结果，不能以 issues 数组为空代替。任何缺陷必须关联原句、定位、内容哈希和依据。

## 五个方法学检查面

### design 研究设计
- [ ] 设计类型是否回答研究问题；主要假设/终点是否事先明确
- [ ] 对照设置能否排除主要替代解释；分组与样本独立性是否成立
- [ ] 随机化、分配隐藏、盲法、批次与混杂控制是否有实际报告
- [ ] 因果结论是否有设计和分析共同支撑

### variables 变量定义
- [ ] 暴露、结局、协变量、分组变量均有操作性定义和测量方式
- [ ] 编码、分类切点、单位换算及时间窗前后一致且有依据
- [ ] 缺失值机制、处理及纳入模型的变量前后一致
- [ ] 连续/分类/计数/生存等变量类型与模型、链接函数匹配

### statistics 统计方法
- [ ] 检验与分布、数据结构、独立性、重复测量相匹配
- [ ] 多重比较校正的范围、方法与结果一致
- [ ] 交互项、协变量调整、敏感性分析有预设依据或清楚标为探索性
- [ ] p、CI、z/t/F、自由度和样本流可复算项过 `statcheck`
- [ ] 未满足关键假设时有合理补救；仅凭检验名称不自动判错

### sample_size 样本量与效能
- [ ] 样本量估算的效应量、来源、alpha、把握度和单双侧均报告
- [ ] 计划量、入组量、分析量与失访/剔除对应；排除比例与结论适用范围相符
- [ ] 实际样本不足被如实讨论，不用事后效能替代效应量/CI解释

### reporting 结果报告
- [ ] 效应量、95% CI、精确 p、统计量与自由度适配所用分析
- [ ] 摘要、正文、表、图注中的样本量、数值、单位和显著性方向一致
- [ ] 主要/次要/探索性终点清楚，阴性与不确定性如实呈现
- [ ] 对照相应研究设计的报告规范；每条规范问题给规范名称与版本/条目

## 六类 review categories（与五面交叉，不替代五面）

| 类目 | 最少记录 |
|-|-|
| `fact` | 哪两个原句/数值/来源冲突；无冲突也写核查范围 |
| `citation` | 哪些方法或统计判断依赖引文，原文是否支持 |
| `design` | 对照、分组、盲法、偏倚及研究问题匹配 |
| `statistics` | 模型匹配与可复算统计报告 |
| `argument` | 结论句与证据句对照，是否过度外推 |
| `compliance` | 伦理、数据/代码可得性、注册、利益冲突等材料是否存在及适用性 |

## 缺陷类型、严重度与状态

- `fact_error`：有证据的冲突；`evidence_gap`：未报告/材料不足；`norm_issue`：有具名规范依据；`suggestion`：可选改进且只能 minor。
- `critical`：已证实且使主要结论不成立/数据不可信。
- `major`：影响可信度但可补救，例如未报告效应量、关键对照不足。
- `minor`：不影响推断的格式、术语或建议性改进。
- `confirmed`：原句、证据与依据均可回查；`pending`：材料/原文/解释不足，必须进入 uncertainty。

## 误报抑制与复核

1. `verify --text` 原句连续存在；不对缺失页、乱码或不可读图下结论。
2. “未报告 X”必须搜过适用章节/补充材料并记录范围；“X 用错”必须有正向方法学证据。
3. `coverage` 分开五面和六类；`statcheck` 提取错误先回原文更正，不直接记作者错误。
4. `gate` 验证每条 quote/evidence 哈希并保留来源全文哈希、原始输出契约和运行版本，使第三人可在相同输入重跑。
