# 审查清单与判定锚点（checklist.md）

## 六类检查项

### 1. fact 事实核验
- [ ] 数值、单位、量纲与稿件自述一致（同一指标前后数字是否打架）
- [ ] 常识性事实与公开事实一致
- [ ] 图表标题/坐标轴单位与正文描述一致
判据：能指出"哪句与哪句/哪个来源冲突"。

### 2. citation 引用支持
- [ ] 被引文献是否支持该论断的方向（支持 / 不支持 / 部分支持）
- [ ] 引用是否为二次引用（转引未读原文）
- [ ] 关键论断是否有引用（不是"有引用"，是"论断有支撑"）
判据：写出被引文献的实际结论与本文论断的差异。

### 3. design 方法设计
- [ ] 是否有对照，对照排除的是哪类混杂
- [ ] 样本量与检验效能是否支撑结论强度
- [ ] 随机化/盲法/批次效应是否处理
判据：说明"缺哪个对照会让哪个替代解释无法排除"。

### 4. statistics 统计报告
- [ ] 检验方法与数据分布/设计匹配
- [ ] 是否报告效应量与不确定性（CI/SD）
- [ ] 多重比较是否校正
- [ ] P 值是否被当作效应大小
判据：指出具体检验名与不匹配之处。

### 5. argument 论证链
- [ ] 结论是否超出证据范围（相关说成因果、体外推体内）
- [ ] 是否存在未排除的替代解释
- [ ] 讨论是否回应了反例
判据：引结论句 + 引证据句，两处对照。

### 6. compliance 学术规范
- [ ] 伦理审批号、知情同意
- [ ] 数据可得性声明
- [ ] 利益冲突、基金标注
- [ ] 图像重复使用、作者贡献
判据：指出缺哪一项声明。

## 严重度锚点

| 级别 | 判定 | 例子 |
|-|-|-|
| `critical` | 结论不成立或数据不可信 | 统计方法用错导致结论反转；图 3 与图 5 疑似同一图像 |
| `major` | 影响可信度但有补救 | 缺效应量；对照缺失使因果表述无支撑 |
| `minor` | 表述、格式、可读性 | 术语前后不一致；单位写法不统一 |

## 误报抑制三条
1. 引文必须**逐字**，跑 `verify --text` 核验；不在原文的条目直接删。
2. 同一 `location + quote` 只报一次。
3. 拿不准的写进 `unchecked`，不要凑数。
