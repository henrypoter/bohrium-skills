# 修订说明（错配通用核心 → v3 专利证据闭环）

既有包记录上一轮区间 59–75、均值 66.9；该数字不是本轮官方实测。检查发现旧目录把本题套成“全部文献子任务 router + 系统综述双人标注”，没有号码角色、族、法律状态、权利要求版本和授权降级机制。本次按题面整体重写，不沿用错配核心。

## 1. 实际效果（40）
- `SKILL.md` 改为号码定位、主题检索、族归并、状态核验、权利要求版本、技术论文六段专用流程。
- 新增 `audit`：逐字引文必须回到实际源文件唯一子串（重复时校验字符 span），来源文件 SHA-256 必须一致；号码/标题/优先权通过 `field_bindings` 重新读取原值比对。
- 简单族/扩展族由优先权和族标识**重算**，结果漏成员或错并会失败；`complete=false`、`claim_scope_equal=false` 为硬约束。
- 当前法律状态非 `official_current` 必须为 unknown；计数 `raw→deduplicated→decisions` 闭合。
- WO/多页 OCR 明确禁止跨段拼引文，权利要求必须带版本和 claim 定位。

## 2. 使用增益（25）
- 新增 `gain` 命令与 `bench/fixtures/gain.json`：同一 case、同权限、同 qrels/k 下真算 P@k、R@k、nDCG@k 与成本差；输入或权限不同直接拒绝。
- `result.json.gain` 分 `platform_observed/local_qrels/not_measured`。平台未给对照时必须为 not_measured，杜绝旧版预填 accuracy/κ 的自证式数字。
- 审计检查本地 qrels 引用、公平性或平台运行标识；效率指标来自实际 tool calls、人工核对数、秒数。

## 3. 创新增益（15）及相对基础 Agent 边界
- `normalize`：基础 Agent 可肉眼改号码；本工具保留号码角色和 kind code，非法角色组合直接失败。**边界**：格式规范不等于真实存在，存在性仍靠原始字段。
- `family`：基础 Agent 易把共同关键词当同族；本工具分简单/扩展族并传递归并、检测优先权冲突。**边界**：不补全在线族，不判断权利要求等同。
- `status`：基础 Agent 易从历史 Grant 推“现有效”；本工具区分当前官方、仅事件、二手、未查、冲突。**边界**：不自动解释法律事件，不替代登记核验。
- `audit`：把授权、字段值、逐字证据、哈希、族、状态和计数合成可重复出口。**边界**：机检不能判断科学相关性是否足够，也不提供法律意见。

## 4. 可靠体验（10）
异常表逐项给出“识别信号 + 动作”：限流/超时、401/403/权限不足、真空命中、法律冲突、状态过期、字段缺失、族不明、OCR 跨页、多源元数据冲突。明确 429 不是零结果，红色来源不展示原文，无法核验就 unresolved/partial。

## 5. 生态贡献（10）
- 重写 `docs/README.md`：安装、完整调用、最小合成示例、五命令边界。
- 重写 `templates/protocol.md`：查询/授权/字段/族/状态/增益协议。
- 重写 `templates/reason_codes.md`：专利筛选、风险、遗漏码。
- 重写 `templates/worksheets.md`：候选、证据、族、事件、授权、迭代遗漏、增益七类表。
- `bench/fixtures/source.json` 是真实可回读的合成最小源，不是正式答案；`good_result.json` 演示完整闭环。

## Bench 证据
运行 `python3 bench/bench_run.py`：**19/19**。五命令均有正向零误杀与变异必命中；变异覆盖伪引文、哈希改变、红色原文、伪造当前状态、伪完整族、漏族、计数断裂、字段错配、权利要求等同及无公平对照增益。

## 距榜首仍需真实评测验证的部分
1. 三个官方固定案例、三次重复及基础 Agent 白板不可见，本轮不能声称 Precision/Recall、官方字段正确率或增益已领先。
2. 工具不联网、不绕权限；官方当前法律状态和完整族只能使用题包实际授权数据，缺失时必须 unknown，可能牺牲表面完整度。
3. USPTO 图像 OCR 与复杂 JSON 字段路径仍依赖 Agent 正确抽取；`audit` 能防拼接/错引，不能替人工识别所有图像错误。
4. GitHub 附加分需未登录公开访问验证；本轮不提交、不 push。
