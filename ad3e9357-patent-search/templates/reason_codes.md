# 专利筛选、风险与遗漏理由码

## 候选判定
| 码 | 判定 | 必要证据 |
|-|-|-|
| P-NUM | 号码及角色精确匹配 | 原号码字段绑定 + 规范化输出 |
| P-TECH | 技术特征匹配 | 摘要/说明书的逐字段逐字引文 |
| P-CLASS | IPC/CPC 与主题范围匹配 | 分类字段及查询映射，不单独证明权利要求覆盖 |
| P-CITE | 由真实引证边发现 | 原始引证关系字段，方向不得颠倒 |
| T-DIRECT | 技术论文直接比较同一方法/对象 | 论文标题或摘要原句 |
| X-SCOPE | 国家、时间、文献类型超出题面 | 对应字段 |
| X-TOPIC | 技术主题不匹配 | 实际标题/摘要，不用空字段反证 |
| U-META | 关键字段缺失或冲突 | 缺失字段名和各源值 |
| U-AUTH | 权限不足无法判断 | 401/403/许可记录，不展示受限原文 |
| U-OCR | OCR 或页段边界无法唯一核验 | 原页与文本定位、具体不清处 |

`include/exclude/unresolved` 均须写自然语言理由；理由码不能替代引文。

## 风险等级
- **高**：当前状态未官方核验；最新官方事件冲突；权利要求版本不明；红色权限；关键号码绑定失败。
- **中**：仅二手元数据；族优先权不全；OCR 可疑；状态快照过期；主题仅标题命中。
- **低**：官方字段完整且当前核验；引文唯一定位；但族完整性和权利要求等同仍不得自动升级。

风险等级表示证据强度，不是专利价值、侵权风险或有效性法律意见。

## 遗漏归因
| 码 | 归因 | 必须定位到 |
|-|-|-|
| M1 | 同义词/跨语言表达未覆盖 | query_id + 缺失术语 |
| M2 | 字段过窄 | query_id + title/abstract/claims/classification |
| M3 | 分类或引证扩展未执行 | IPC/CPC 或 edge 查询 |
| M4 | 快照/数据库未覆盖 | source_id + 版本/日期 |
| M5 | 权限或接口失败 | source_id + 401/403/429/超时 |
| M6 | 号码或 OCR 异常 | record_id + 字段/页段 |
