# 修订说明（v2，判对证据闭环）

本轮保留原有 DAG、字段映射、权限和幂等设计，没有推倒重写；新增的是可执行判对闸和真实产物核验。所有 bench 均为合成夹具，不是官方答案或平台得分。

## 实际效果 40：六类要素从自述变成硬校验

- `audit` 新增任务状态、浏览器/API/软件操作、权限、数据传递、失败恢复、同步冲突六类覆盖检查。已执行步骤无定位操作、done 无状态快照、映射无转换、权限引用失效、失败无分类恢复、冲突未裁决仍 pass 均返回非零。
- `resume` 计算依赖已满足的步骤，done 不重放，blocked/skipped 进入人工接管集，直接回应“中途失败接着跑”。
- `manifest`/`verify_manifest` 对真实字节计算并重算 size/SHA-256，补足中间产物和恢复记录的独立可复核性。
- `schema` 新增 `schema_version/skill_version/run_version`，并从原始 case 读取 `output_contract`，检查原字段未丢失以及 case 要求的来源数。

## 使用增益 25：减少整链重跑和事后核对

续跑由状态而不是模型记忆决定，操作和状态都有定位；映射、权限、计数在写入后可一次机检。`gain` 仅接收同输入、同权限的真实对照，未提供时保持 null，不声称已经优于基础 Agent。

## 创新增益 15：状态证据图 + 双版本冲突 + 可重算清单

相对基础 Agent 常见的自然语言操作叙述，本版新增：①状态机与操作证据联结；②权限引用和 yellow/red 数据处理机检；③登录/跨域等禁止自动绕过的策略闸；④冲突左右版本留存；⑤产物字节哈希可独立重算。边界：工具验证结构与文件真实性，不替平台证明网页语义或科学结论，也不在缺权限时制造成功。

## 可靠体验 10：异常表补全并可检测

登录失效、二次认证、跨域、元素缺失、超时、限流、权限拒绝、下载失败、写入报错、同步冲突均规定检测、处置、结果和检查点。登录/跨域/权限异常自动重试会被 `audit` 拦截。CLI 对缺参数、坏 JSON、缺文件返回结构化错误，不以 traceback 冒充检查结果。

## 生态贡献 10：复用资源与版本

保留 `templates/flow_spec.md`，SKILL 给出 Datasette 分页/过滤/CSV/HTML 与 SQLite 事务证据要求、最小合成调用示例、完整异常表和增量 result 契约。所有脚本仅 Python 标准库。

## 机器证据

`python3 bench/bench_run.py`：**32/32 PASS**。覆盖 `flow_check/schema/audit/resume/manifest/verify_manifest` 的正向零误杀和针对性变异，包括真实文件篡改必命中。该结果仅证明工具判对闸行为，不替代固定案例实际运行，也不是榜首对照分数。
