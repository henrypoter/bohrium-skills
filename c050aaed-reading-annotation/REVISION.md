# 修订说明（重做）

本题此前套用了通用「文件落库」核心（目录/元数据/哈希/版本链），与题面要求的「批注提取—笔记结构化—知识关联—检索」严重不匹配（58.33 分，rank 12）。本轮**重做**为批注专用方案，逐项对齐题面六个痛点：

| 题面痛点 | 对应机检 |
|-|-|
| 锚点错位（OCR漂移/双栏串行） | `anchor_check --text` 每条批注引文逐字回原文，错位直接抓出 |
| 类型与标签丢失 | 类型限定五类、highlight/underline 强制保留颜色 |
| 笔记退化为摘抄 | `note_check` 每条论断必须有支撑且定位到页/段 |
| 知识关联靠关键词重合 | `link_check` 每条关联必须有 ≥8 字明确依据，"都提到X"被拒 |
| 版本串味 | `version_check` 按 sha256 归并重复/多版本，批注挂逻辑文档 |
| 过程不可复现 | `schema` 强制文件 sha256 + script_version |

判对三件事（逐条回原文/论断有支撑/可复跑）分别由 anchor/note/schema 三命令闭环。创新点选「扫描件批注锚点校正 + 批注到笔记再到检索贯通」。
