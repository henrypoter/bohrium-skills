# 图稿规格（figure_spec.md）

## 可编辑性
- 文字保留为 `<text>`，**不转曲**（`svg_check` 会抓"无 text 全 path"）。
- 图层/分组命名可读，便于后续编辑。

## 元素-数据映射
| 元素 | 来源 | 来源定位 |
|-|-|-|
| rect1 | data.csv | A 列 |
| line1 | table2 | 第 3 行 |

图上每个数据点/标签都要能回指到来源；未映射元素会被 `element_map` 抓出。

## 标注与导出
- 图注独立可读：单位、图例、误差线定义、样本量、子图编号。
- 双交付：可编辑 SVG 源 + 渲染 PNG（≥300dpi，字体嵌入）。
