# bohrium-skills

Bohrium 产品周赛·第四周参赛 Skill 合集。每个子目录是一个可独立加载的 Skill。

共 75 个 Skill，本轮新增：10 个「领域总课题」改为分诊路由器（先判子任务类型→统一核心流程+出口机检），2 个无分题（前沿趋势、跨网站工作流）重做为专用方案。**远端当前只推送了文献检索 12 个**，其余为本地维护版本。
