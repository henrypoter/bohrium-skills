# 能力矩阵与边界（positioning）

回答创新增益评分点：本成果相对「通用写作 Agent / 文献管理与润色工具 / 纯人工返修流程」具备什么、不具备什么。结论均可用 `bench/bench_run.py` 复跑核对，不做无依据声称。

## 一、能力矩阵对照

| 能力 | 通用写作 Agent（无本 Skill） | 文献管理/润色工具 | 纯人工流程 | 本 Skill 流程 |
|---|---|---|---|---|
| 意见拆解为条目+子要求 | 能做但不稳定，长意见易漏子要求 | 不做 | 能，靠人工逐条 | 机器解析（编号/子要求/引文比对）+ Agent 复核 |
| 类型/严重度/处置级别标注 | 无固定分类法，每次自由发挥 | 不做 | 凭经验 | 固定分类法：类型 5 类+严重度 4 档+处置 L1-L4（机器建议值） |
| "已修改"声明与稿件一致性机器核查 | 无，靠自觉 | 不做 | 人工逐条回查 | verify 锚点全文检索，虚构锚点必 fail（夹具证明） |
| 反驳/无法执行条目合规核查 | 无 | 不做 | 靠经验 | 三要素（证据+替代方案+缓冲语）缺一即 fail |
| 对抗性语气扫描 | 无 | 部分润色工具有语气建议 | 靠自觉 | TONE 词表扫描 warn + 四档句型库 |
| 意见-回复-修改三列闭环矩阵 | 无，手工整理 | 不做 | 手工表格 | matrix 命令机器生成骨架，Agent 回填 |
| 锚点行号两阶段回填 | 无（改稿后行号漂移） | 不做 | 手工数行号 | verify 命中后回填行号+最近标题 |
| 修改留痕 diff | 无 | 部分有版本对比 | 依赖编辑器 | trace 命令 unified diff |
| 疑似误解检测（意见引文与稿件比对） | 无 | 不做 | 人工发现 | 引文抽取+全文比对，找不到即标注 |
| 科学内容正确性判断 | 依赖模型能力 | 不做 | 人 | **不做**：脚本只核查"声明与稿件一致"，科学判断留给 Agent 并写入 uncertainty |
| 正文写作/改写质量 | 依赖模型能力 | 语法层面 | 人 | 不替代：本 Skill 管闭环与核查，写作仍由 Agent 完成 |

## 二、新增能力（基础 Agent 难以稳定实现的部分）

1. **机器可核验闭环**：回复信每个「锚点」必须原样存在于修订稿，否则 verify exit 1——把"改得准"从口头承诺变成可重算事实（变异夹具：虚构锚点必命中）。
2. **反驳合规机器拦截**：L3/L4 条目缺证据/替代方案/缓冲语即 fail——把"礼貌反驳三要素"从写作建议变成硬关卡（变异夹具：缺缓冲语必命中）。
3. **锚点两阶段回填**：起草用稳定结构锚点，定稿后机器回填行号+标题，消除改稿后行号漂移（正向夹具：跨行锚点命中并回填第 3 行/摘要）。
4. **三元标注分类法**：类型+严重度+处置级别 L1-L4 的机器建议值，使台账、矩阵、回复信三处分类口径一致。

## 三、边界（明确不做什么）

1. **不判断科学正确性**：脚本是"一致性核查器"，不是"审稿人"；事实与科学结论由 Agent 结合材料判断，存疑写入 result.json uncertainty。
2. **不联网核验**：公开论文/报告链接只作来源身份，不声称已联网核对原评审全文。
3. **不生成材料外证据**：证据槽位只从稿件原文/diff/材料内填充；无法补做的实验如实标注，禁止虚构（模板禁止事项+verify location 关卡双重约束）。
4. **分类仅为建议**：类型/严重度/处置级别是关键词词表建议值，最终由 Agent 复核；词表可按学科扩展，属维护项。
5. **不覆盖全学科全期刊**：面向"意见清单+指定版本稿件基线"的受控返修场景；无意见纯润色、无基线稿件不适用（SKILL.md 适用条件）。
6. **短材料夹具，不声称长文端到端表现**：bench 仅证明机制正确性与确定性路径增益；三个固定案例的端到端结果以平台 harness 为准。

## 四、相对已有工具的价值一句话

通用写作 Agent 让"写回复"变快，本 Skill 让"回复的每一条可机器复核"：答得全（coverage 关卡）、改得准（location 关卡+行号回填）、证得住（rebuttal 三要素+证据清单）、对得上（matrix+diff+verify 三件套），且全部确定性路径不耗模型请求。
