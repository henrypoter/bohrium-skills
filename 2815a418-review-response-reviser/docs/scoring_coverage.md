## 未覆盖项（如实声明）

1. **LLM 端到端写作质量对照**：需要平台 harness 运行固定案例，本地只有确定性路径对照，故第 5 条标「部分」。
2. **子要求级机器覆盖核对**：verify 核对到意见编号级，一条意见内多个子要求的逐条结论靠台账+自查清单，机器不逐条核对，故第 3 条标「部分」。
3. **长稿件与多轮返修端到端实测**：夹具为自拟短材料，仅证明机制正确，不代表长材料表现，故第 12 条标「部分」。
4. **科学事实本身的正确性**：脚本核查「声明与稿件一致」，不判断科学内容对错；该判断由运行 Agent 结合材料完成并写入 uncertainty。
