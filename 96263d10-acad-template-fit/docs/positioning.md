# 相对现有方案的边界与价值（创新点定位）

回答评分点「是否证明创新点相对已有方案的边界和价值」：逐项给出已有方案能做什么 / 不能稳定做什么，以及本 Skill 的边界。

## 2. 三个创新点及其边界

**（1）模板 → 检查项清单（认得准）。** 不凭经验猜规格：每条要求落到 `key/值/单位/来源文件/行号`，多份规定冲突时保留全部值并 flag（实测：guide GB/T 7714 vs PDF IEEE、docx 1cm vs tex 3cm 边距均正确 flag）。边界：只抽取有规则 key 的规格；自由文本排版描述（如"标题层级样式"）无规则覆盖，进 `unverified_items`。

**（2）确定性幂等改稿（改得到位）。** spec → preamble 改写是函数式的：同输入必同输出、绝不改源稿、二次运行零改动；改动以 unified diff + JSONL 留痕，可逐条复核或回滚。边界：**只覆盖 preamble 级规则**（纸张/边距/栏数/字号/行距/文献样式/字体映射）；图注表注搬移、标题层级绑定等正文级编辑明确留给模型逐处留痕，不假装自动。

**（3）告警式交付（交得出）。** 判定不 fail-closed：编译失败/合规缺失照常交付可编辑源 + PDF（若有），errors/warnings 进 uncertainty，status=partial（实测 mutation C 缺字体：deliver=true、level=partial、退出码 0）。边界：告警不等于放行——fidelity 计数不一致必须调查，否则只能 partial。

## 3. 与「基础 Agent」的差异证据

`bench/bench_run.py` 在三条自拟样例上对照同一任务：全功能路径动作数 55→11（-80%），**主路径 lean 55→6（-89%，每样例 2 条命令）**，模型上下文 4003→767 字符（lean，-81%），机器可判定检查项 0→35，可复核产物 3→16（lean 17），留痕 0→7 条。属确定性路径对照，可一键复跑；不涉及 LLM 质量评分（边界见 `bench/bench_report.md`）。

## 4. 不做什么（明确边界，避免过度声称）

- 不做语言润色与学术正确性判定：只处理格式与保真，不评判内容科学价值。
- 不做 docx 确定性改稿：docx 为「复制可编辑源 + `soffice` 渲染 PDF 预览 + 样式项列 `unverified`」的半自动路径。
- 不内置官方模板 hash 库：指纹只记录与留痕，不判定"模板过旧"。
- 不联网、不补造材料：缺 .bst/缺字体/版本不明写 uncertainty，不下载不编造。
- 不覆盖全部排版规则：无自动规则项一律列 `unverified_items` 交人工。
