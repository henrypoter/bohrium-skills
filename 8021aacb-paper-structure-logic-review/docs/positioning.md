## 2. 相对语言润色类工具的边界与增量（创新证据口径）

- **增量**：润色工具优化「句子怎么写」，本 Skill 判定「哪句该留、该移、该收窄」，输出是编辑动作（move/merge/split/narrow/add_transition/delete/rewrite_sentence）而非润色稿；每条判定可指回原文锚点与判据，作者能逐条采纳/驳回。
- **互补不替代**：本 Skill 不做语言层全面润色（语法、用词、风格归润色工具）；L1 仅做衔接/标点级最小改动。
- **可核验证据**：`bench/fixture_test.py` 证明判据「正向零误杀、变异必命中」；`bench/path_compare.py` 证明相对「无诊断直接重写」在事实漂移/留痕/锚点口径上的确定性差异（流程级，非 LLM 端到端质量声称）。

## 3. 明确不做什么（边界声明）

1. 不做学科正确性判断（公式对错、实验设计优劣）；不补实验、不代写结论、不增删文献主张（越权请求拒绝并标 human_confirmation）。
2. 语义代理不是神经句嵌入：换说法重复只召回候选，判定权在 LLM 仲裁+原文证据。
3. 启发式信号（缺章节、截断、篇幅失衡、zone 功能分类）均为候选告警，须模型回原文核实后才入 diagnosis。
4. 非学术体裁（新闻、公告等）只给体裁告警与可读性提示，不强行套学术六维判缺陷。
5. PDF 依赖外部转文本工具；扫描件无文本层不在适用范围。
