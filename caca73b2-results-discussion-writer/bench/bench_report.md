# Bench 报告：确定性路径对照与回归夹具

复跑方式：`python3 scripts/bench_run.py --write`（纯标准库，约 1 秒，退出码 0 表示全部断言通过）。
本报告数字为最近一次实跑结果（`bench/bench_results.json` 原样存档）。

## 1. 夹具设计（均为自拟材料，非正式案例）

| 夹具 | 学科/语言 | 作用 | 预期 |
|---|---|---|---|
| `cases/bio_good` | 生物医学/中文，2 图 1 表 6 数值 | 正向夹具 | 零误杀：exit=0, fail=0, warn=0 |
| `cases/phys_good` | 材料学/英文，Fig./Table 编号，10 数值（MPa/°C/°C·s⁻¹/g·cm⁻³） | 换学科、换图表编号、换数据量的正向夹具 | 零误杀 |
| `cases/degraded` | 缺统计输出、无参考文献、单位表述混乱（mg/L 与"毫克/升"） | 异常场景下的诚实降调写法 | 零误杀（降调句不被误判为过度宣称） |
| `cases/bio_mutant` | 与 bio_good 同材料，注入 10 项已记录失败模式 | 变异夹具 | 必命中：exit=1 且 10 项预期全部检出 |

变异稿注入的 10 项错误预期：引用不存在的图 3（fig_ref fail）、图 2 声明未引用（fig_ref warn）、
对不显著数据用"显著改善"（claim fail，spin）、结果段混解释词+文献引用（purity warn×2）、
无来源数值（number warn）、t(18)=3.21 配 p=0.2 转录错误（statcheck warn）、
S7 significant=true 与 p=0.2 自相矛盾（source_consistency warn）、缺局限小节（structure warn）、
讨论缺局限落位（discussion_block warn）、因果表述无缓冲词（claim warn）。

## 2. 实测结果（全部通过）

| 夹具 | exit | fail | warn | 数值溯源 | 断言 |
|---|---|---|---|---|---|
| bio_good | 0 | 0 | 0 | 6/6 | 通过 |
| phys_good | 0 | 0 | 0 | 10/10 | 通过 |
| degraded | 0 | 0 | 0 | 3/3 | 通过 |
| bio_mutant | 1 | 2 | 10 | 5/7 | 通过（10/10 预期命中，漏检=[]） |

超长输入稳定性：phys_good 内容重复 200 倍（228800 字节），判定不变（fail=0/warn=0），耗时 0.37s（限 10s）。

## 3. 使用增益的确定性路径对照（同一材料）

| 度量 | 直写不核查路径（bio_mutant 模拟基础 Agent 常见失败模式） | 本核查流程路径（bio_good） |
|---|---|---|
| fail | 2 | 0 |
| warn | 10 | 0 |
| 按评分维度（直写路径） | 正确性 1f/5w；完整性 1f/2w；可核验性 0f/2w+2i；完成度 0f/1w | 全部清零 |
| 错误检出数 | 10/10 注入错误全部被 rd_check 检出（即可定位可修复） | — |
| spin/强表述检出数 | 2（不显著数据用"显著改善"fail；"证明/导致"无缓冲 warn） | 0 |
| 产物数 | 1（草稿） | 4（sources.json 证据清单 + draft.md + report.json 核查报告 + result.json 契约结果） |
| 核查耗时 | 0.16s | 0.09s（零模型请求） |

效率面：核查步骤不消耗模型请求（SKILL.md 预算纪律步骤 0/4 用脚本）；fail/warn 逐条带行号与来源 id，
返工定位从"通读全文"降为"按 report.json 逐条处理"。

## 4. 诚实声明的边界（不声称什么）

1. 本 bench 是**确定性规则可判定维度**的路径对照（数值溯源、图表引用、宣称强度、结构、统计量重算），
   不度量语言流畅度、论证深度等需模型/人工评判的质量；那部分对照由平台固定案例的基础 Agent/Skill Agent 双跑给出。
2. 变异稿的失败模式取自公开文献与基础 Agent 常见错误的记录（见 ../docs/positioning.md），是模拟而非正式案例实测。
3. statcheck 重算仅覆盖 t/z（近似，只 warn 不 fail）；F/χ²、OR/RR 等未实现。
4. 数值匹配按书写精度容差（四舍五入 ≤0.5 ulp），不判断"数值本身算得对不对"（如均值是否等于原始数据均值）。
5. 正向零误杀仅在随包 3 个正向夹具上验证；新学科写作风格可能触发未知误报，warn 设计为人工逐条确认而非强制拦截。
