# 修订说明（v1 → v2）

## 实际效果（40）：数值可被机器复算
v1 只做字段存在性校验，无法判断数值对不对。v2 新增 `data_tool.py recheck --csv`：从原始数据**重算** sum/count/mean/min/max 并与上报值比对（相对容差 1e-3），不一致直接失败。这对应「数值能否独立复算」。另新增 `profile` 输出缺失/重复行/IQR 异常值/量级不一致/脏数值，回应「选择与解读是否站得住」。

## 使用增益（25）
`result.json` 增 `gain`，要求同快照同权限下基础 Agent 与 Skill 对照，报正确率与返工轮次。

## 创新增益（15）
按数据字典做字段语义接地（编码型字段不当连续变量）、连接膨胀检测（先验基数）、脏数据规则化（`dirty_numeric_count` 定位）。

## 可靠体验（10）
6 行异常表：空结果、连接失败/权限、字段歧义、重复记录、类型不一致、单位不一致，各给判别方法与动作。

## 生态贡献（10）
新增 `templates/data_dictionary.md`：字段字典表 + 连接膨胀与聚合粒度两类模式 + 交付前复算清单。
