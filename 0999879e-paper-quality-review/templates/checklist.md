# 论文质量审查清单 v3（与 result_schema_version 2.0.0 配套）

## 使用规则

- 每个分面都必须登记 `checked / partial / not_applicable / not_checked`；零 issue 不是 checked 的证据。
- 每条 issue 都有真实 `location/quote/quote_sha256`、至少一个 `evidence`、一个 `basis`、可执行 `fix`；完成后跑 `verify + coverage + schema`。
- 先区分 `fact_error / insufficient_evidence / normative_issue / suggestion`，再定严重度；不确定即 `needs_review`，不凑数。

## fact：事实核验

- [ ] 同一指标在摘要、结果、讨论、图表中的数值/单位/方向是否一致？冲突双方是否都逐字引用？
- [ ] 样本量、时间、剂量、比例是否与设计及结果一致？如声称重算，是否保存输入、公式和结果？
- [ ] 外部事实是否来自本次实际允许的来源，且依据 locator 可回查？

**成立锚点：** 两个来源/句子存在可核对的冲突；**排除：** 单纯不同四舍五入、不同亚组、不同时间点不能直接判错。

## citation：引用支持

- [ ] 数字引用运行 `citations`；作者—年份手工配对，不断言已自动覆盖。
- [ ] 本文论断原句是什么？被引文献实际主张原句是什么？方向、对象、条件、强度是否一致？
- [ ] 题录是否存在且元数据有实际来源？引用是否只是相关而非支持？

**成立锚点：** `supported/contradicted/partial/unclear` 对照及双 span；**排除：** 只有题录匹配、没有全文时不得确认“引而不证”。

## design：方法设计

- [ ] 对照组能排除哪个替代解释？无对照是否仍出现因果结论？
- [ ] 样本量、抽样、纳入排除、随机化、盲法、重复和批次是否说明？
- [ ] 是设计本身不能回答研究问题，还是设计可接受但报告不全？

**成立锚点：** 方法 span + 结论 span + 缺失环节；**排除：** 学科允许的非随机/描述性设计不能一律判错。

## statistics：统计报告

- [ ] 检验是否匹配独立/配对、分布、测量层级及重复结构？
- [ ] 效应量、CI/误差、精确 P 值、多重比较、样本量是否按研究设计报告？
- [ ] P 值是否被当成效应大小/临床意义？缺失是否影响主结论？

**成立锚点：** 具体方法与数据结构不匹配；**排除：** 未提供原始数据时只判报告不全，不虚构重算结果。

## argument：论证链

- [ ] 假设 → 方法 → 结果 → 结论的哪一步缺少连接？
- [ ] 相关是否被写成因果？样本/模型/体外结果是否外推到未研究人群或场景？
- [ ] 是否忽略与数据相容的关键替代解释或反例？

**成立锚点：** 证据句 + 结论句，说明需要增加何种证据或缩小何种表述；**排除：** 有合理限制的推测不直接判逻辑错误。

## compliance：学术规范

- [ ] 数据可用性、伦理/知情同意、利益冲突、作者贡献、图表来源是否与材料及目标要求相符？
- [ ] 规范依据是否有实际版本、日期、条款定位？
- [ ] 缺失声明是否记录完整搜索范围，而非只写“没看到”？

**成立锚点：** 实际条款 + 稿件锚点 + 缺失/冲突；**排除：** 未提供目标指南时不得凭空制造格式问题。

## 严重度与修复锚点

| 级别 | 可核对锚点 | fix 示例 |
|-|-|-|
| critical | 已核实的问题直接动摇核心数据/结论 | 指名需更正/重算的结果和受影响结论；无法判哪个数值正确则 needs_review |
| major | 关键证据、对照、引用或规范依据不足，但可通过补资料/收缩结论补救 | 在指定句增加效应量/对照限定，或补实际被引证据 |
| minor | 不改变科学结论的局部一致性/格式问题 | 在指定位置统一术语、单位或引用格式 |

禁止输出 `fix.target=注意`、`instruction=建议检查`。修改建议必须让作者知道改哪个句子、补什么证据、达到什么条件。
